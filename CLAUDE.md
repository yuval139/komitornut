# CLAUDE.md

This repository holds only the built site of the Komitornut app (under `site/`), served on GitHub Pages at https://yuval139.github.io/komitornut/.

**Do not work here.** The source code, the tests and the instructions live in the private repository `yuval139/komitornut-src`. Its publish workflow builds the app and pushes the result into `site/`. Anything edited here by hand is overwritten by the next publish, and anything committed here is public.

If you were asked to change the app, attach `yuval139/komitornut-src` and work there: its CLAUDE.md explains how. Never upload source code, crew data or an older copy of the app to this repository.
