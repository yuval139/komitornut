# תורנויות · קוממיות — העלאה כאפליקציה

## מה יש בתיקייה

| קובץ | מה הוא |
|---|---|
| `index.html` | הדף הראשי |
| `app.js` | האפליקציה (כבר מתורגמת — נטענת מהר) |
| `vendor.js` | React, כלול בתוך התיקייה (לא צריך אינטרנט כדי לטעון אותו) |
| `assets.js` | תמונת הבאנר |
| `manifest.json` | שם, צבעים ואייקון של האפליקציה |
| `sw.js` | מאפשר לאפליקציה לעבוד גם בלי אינטרנט |
| `icons/` | האייקונים למסך הבית |

---

## שלב 1 — להעלות לאוויר (חינם)

1. היכנס ל־**app.netlify.com** ופתח חשבון חינמי (כדאי — ככה הכתובת נשמרת ואפשר לעדכן אותה).
2. **Add new site → Deploy manually**, וגרור לשם את **כל התיקייה** `komitornut-pwa` (או את קובץ ה־zip).
3. תוך כמה שניות תקבל כתובת. אפשר לשנות אותה לשם נורמלי: **Site configuration → Change site name** (למשל `komemiyut-toranuyot`).

## שלב 2 — להתקין בטלפון

- **אייפון:** פתח את הכתובת ב־**Safari** (חייב ספארי) ← כפתור השיתוף ← **"הוסף למסך הבית"**.
- **אנדרואיד:** פתח בכרום ← שלוש נקודות ← **"התקן אפליקציה"**.

מעכשיו יש אייקון במסך הבית, האפליקציה נפתחת בלי סרגל דפדפן ועובדת גם בלי אינטרנט (אחרי הפתיחה הראשונה).

## שלב 3 — להעביר את הנתונים שכבר יש לך (חשוב!)

האפליקציה החדשה נפתחת **ריקה מהנתונים שלך** — הנתונים שמורים בנפרד בכל כתובת. כדי להעביר את הכל (צוות, היסטוריה, סגירות, החלפות, הסמכות):

1. בקישור הישן: גלגל שיניים ← **שיתוף** ← **שליחה** ← בחר סיסמה ← **צור קוד** ← העתק.
2. באפליקציה החדשה: גלגל שיניים ← **שיתוף** ← **קבלה** ← הדבק את הקוד והסיסמה.

## גיבוי

הנתונים שמורים רק בטלפון. פעם בשבוע (למשל אחרי שמירת הסידור) צור קוד כמו בשלב 3 ושמור אותו אצלך בוואטסאפ או בפתק.

## עדכונים

כשאשלח גרסה חדשה: ב־Netlify, בתוך האתר ← **Deploys** ← גרור את התיקייה החדשה. הטלפונים יקבלו את העדכון בפתיחה הבאה כשיש אינטרנט.
